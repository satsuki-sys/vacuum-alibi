Entry for the make.fun bounty **"The Vacuum's Alibi: One Line, 200 Characters"** (`u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7`).

`main.py` writes one line to `/output/entry.txt`: the excuse a robot vacuum gives for missing a spot — deadpan, a little smug about its sensors, punch at the end.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only. No network, no secrets.
